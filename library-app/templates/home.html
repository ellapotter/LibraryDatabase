  • Add New Reservation Query: This query uses an insertion statement to add the user input values to the Reservation table
  • Request Checkout Query: This query inserts a new row into the CheckoutRequest table with a pending status. The material availability stays available until staff accepts the request.
  • Display Profile Information Query: This query uses a select statement to retrieve the information from the Patron table where the patron_id matches the logged-in user's patron_id
  • Display Checkouts History Query: This query joins the Checkouts and Material tables on material_id and uses a where clause to find the checkouts for the logged-in patron
  • View Checkout Requests Query: This query joins CheckoutRequest and Material to display the logged-in patron's checkout requests and their current request statuses.
  • View Library Fees History Query: This query displays the logged in patron's total unpaid fees amount alongside their fees table. The query uses an aggregate function (COUNT and SUM) to find these totals and joins Patron to Fee to view only the specific patron's data.
  • View Cafe Order History Query: This query uses a select statement to retrieve the information from the CafeOrder table where the patron_id matches the logged-in user's patron_id
  • View Your Room Reservations Query: This query displays the logged in patron's upcoming reservations alonside their reservations table. The query uses the Patron_Reservation_View which returns only reservations for the current patron, it then filters those reservations whose dates fall after today's date.
  • View Your Event Registrations Query: This query uses a select statement to retrieve the information from the Registration table where the patron_id matches the logged-in user's patron_id
  • View All Library Materials Query: This query uses a select statement on the patron view for the materials to limit which book and film information the patron sees
  • Search Library Book Collection: This query displays a variety of relevant book information using a join of the Book table to the BookISBNConnector table on the shared isbn attribute and then joins the Material table on the material_id attribute, limiting the results with a where clause to only books whose title matches what the user types in
  • Search Library Film Collection Query: This query displays a variety of relevant film information using a join of the Film table to the FilmConnector table on the shared imdb_id attribute and then joins the Material table on the material_id attribute, limiting the results with a where clause to only films whose title matches what the user types in
  • Update Profile Email Query: This query updates the email address in the Patron table where the patron_id matches the patron_id of the logged-in patron
  • Delete Reservation Query: This query deletes the entry from the reservation table whose reservation_id matches the id the user inputs

  • Checkout Material for Patron Query: This query inserts the selected available book or film and patron ID into the Checkouts table with today's date as the checkout date and the selected due date. The checkout trigger updates the material availability to checked out.
  • Create New Patron Account Query: This query uses an insert into statement on the Patron table to add a new account with the input values
  • Update Patron Email Query: This query updates the email address in the Patron table where the patron_id matches the input patron_id
  • Display Profile Information Query: This query uses a joins the Staff table with the Role table on the matching roleID attribute and then uses a where clause to filter to just the logged in staff member's information
  • Display List of All Library Patrons Query: This query uses the asterisk wildcard character to display all of the patron information in the Patron table
  • View Patrons with Current Checkouts Query: This query joins the Patron table to the Checkouts table on the shared patron_id attribute, then uses a where clause to identify checkouts with a return date that is null (meaning the book has not been returned yet) and where the material_id matches the material_id in a subquery on the material table that finds any material whose availability attribute has the value 'checked out'.
  • View All Library Materials Query: This query uses a select statement on the patron view for the materials to display the book and film information in the library collection
  • All Books Query: This query uses a select statement to retrieve the books in the Book table
  • All Authors Query: This query uses a select statement to retrieve the authors in the Author table
  • All Films Query: This query uses a select statement to retrieve the films in the Film table
  • All Directors Query: This query uses a select statement to retrieve the directors in the Director table
  • View All Checkouts Query: This query uses a select statement on the Checkouts table to display every checkout record, including materials that have already been returned.
  • Add Book to Collection Query:This query collects a variety of book information from the user. It checks if the author is already present in the Author table and if the book is already present in the Book table and adds them if not. It also adds the new material to the Material table.
  • Add Film to Collection Query:This query collects a variety of film information from the user. It checks if the director is already present in the Director table and if the film is already present in the Film table and adds them if not. It also adds the new material to the Material table.
  • Search Library Book Collection Query: This query displays a variety of relevant book information using a join of the Book table to the BookISBNConnector table on the shared isbn attribute and then joins the Material table on the material_id attribute, limiting the results with a where clause to only books whose title matches what the user types in
  • Search Library Film Collection Query: This query displays a variety of relevant film information using a join of the Film table to the FilmConnector table on the shared imdb_id attribute and then joins the Material table on the material_id attribute, limiting the results with a where clause to only films whose title matches what the user types in
  • View Total Checked Out Materials Query: This query uses count as an aggregate function after joining the Material and Checkout tables on material_id and filtering the results with a where clause to only materials whose return date is null (meaning they are still checked out)
  • Update Room Reservation Query: This query updates the Reservation table to change a pending reservation's status to confirmed or denied based on the reservation_id the staff member inputs
  • Update Checkout Status Query: This query updates a pending checkout request to accepted or denied. Accepted requests create a row in Checkouts with the chosen due date and trigger the material availability update to checked out.
  • Return Material Query: This query updates the Checkouts table by setting the return_date to today's date for the matching patron ID and material ID. The return trigger updates the material availability to available.
  • Apply Late Fees: This query uses the apply_late_fees procedure to add a late fee to patrons with a material that has not been returned and whose due date has passed
  • Delete Patron Account Query: This query uses a delete statement to remove the patron from the Patron table based on the patron_id the user inputs
  • View Late Fees: This query uses a select statement to retrieve the fees in the Fee table
